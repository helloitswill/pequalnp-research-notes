# Removing leaves from an edge-detection circuit

For the L-meta-612 gate count, the lower bound lifts across three reductions. These are written proofs for arbitrary monotone circuits with shared wires. They also give a direct proof of the bound on all forests. The project has a related machine-checked pendant lemma for a larger circuit basis. [Project lemma L-meta-547](https://github.com/brilliant-hq/pequalnp-proofs/pull/594)

Use a minimum circuit with constants and unary gates propagated, repeated operands removed, and every gate connected to the output. Fixing a primary bit removes every gate directly reading it, since an AND or OR with one constant operand either becomes constant or passes through the other operand. Every gate reading a newly constant gate can also be removed. After simplifying, the residual program is still monotone. Whenever the graphical target below is nonconstant, the residual circuit needs no constant gate.

1. **A cover-preserving leaf costs a gate.** If b is a leaf and deleting it preserves τ, set b to false. Since b belongs to an edge, some gate reads it. The shortened circuit detects edges of G−b. The proposed minimum also decreases by one.
2. **An isolated edge costs two gates.** Suppose ab forms its own component and the rest of the graph has an edge. Fix a = b = false. If two distinct gates directly read those inputs, both disappear. Otherwise the sole gate reading them must take a and b as its two inputs. It becomes constant, and at least one later gate reads it because the output also depends on the rest of the graph. That later gate disappears as well. Both |E| and τ decrease by one.
3. **A pendant path of two edges costs three gates.** Suppose b is a leaf adjacent to a, and the only other neighbor of a is v. The old graph, after deleting a and b, has edge function g. Assume g has an edge. The target is then g ∨ (a ∧ (v ∨ b)), writing the same letters for the primary inputs. Set a = false. Either value of b now leaves exactly g, a nonconstant function.

   Let U be the set of gates directly reading a or b. Both inputs are essential. If U has at least three gates, setting both inputs to constants removes them. If U has one gate, its two inputs must be a and b, and all later signals are symmetric in a and b. On the old assignment selecting only v, the target equals a. This rules out the one-gate case.

   Suppose U consists of two gates. A gate directly reading b can be forced constant by setting b to false at an AND or true at an OR. Such a gate cannot itself be the output, since it would then be constant while the restricted target is g. If any b-reading gate feeds a gate outside U, force that b-reading gate constant. The two gates in U and this third gate disappear.

   Otherwise the later of the two gates cannot read b. It would need a consumer outside U. The earlier gate therefore reads b, and its only consumer is the later gate, which must also read a. Force the earlier gate constant using b. The later gate now reads that constant and a = false, so it too is constant. Since the target is g, the later gate cannot be the output. Its consumer is a third gate that disappears.

   Removing a,b deletes two edges and decreases τ by exactly one. Any cover must pay for ab in addition to covering the old graph, and adding a to an old minimum cover suffices. Thus the saved three gates match the change in the proposed lower bound. If the old graph has no edge, removing isolates leaves the three-vertex path, which takes two gates.

To apply the rules to a forest, choose a longest path in a nontrivial component. If the component is a single edge use rule 2, with a single remaining edge as a base case. Otherwise every off-path neighbor of the second vertex of that path is a leaf. A longer branch there would extend the chosen path. If there are several leaves with this parent, deleting one preserves the cover number by replacing a surviving leaf with its parent in a minimum cover. Apply rule 1. If there is only one leaf with that parent and the parent has degree two, apply rule 3. Stars and the case where only isolated vertices remain are covered directly. Induction and the star construction give the exact count.

In a search at any fixed cover size, testing whether a leaf preserves τ can save substantially more work than removing duplicate leaves alone. Relabel the surviving graph and use the established result for the smaller instance. These reductions also apply to graphs containing cycles.
